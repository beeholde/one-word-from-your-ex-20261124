One Word From Your Ex — a make.fun entry. The program writes exactly one word to `/output/entry.txt`: the word the entrant's ex would use to describe them. **Spare** — the one kept in reserve, only reached for when the real thing fails: a spare tyre, a spare key, a spare plan. It lands instantly, needs no explanation, and stings because it is true.

## Run it

```sh
python3 main.py
```
